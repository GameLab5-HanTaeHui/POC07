# Key_BOSSKnight — 봉인된 기사 보스 기획 문서

Unity 버전 6000.3.10f1 | 2D Universal | namespace : KEY

---

## 개요

테스트 미니 보스 하나 개설

이름: 테스트 미니 보스
패턴 시전 이전 차징으로 기술 예측도가 나옴.
차징 끝난 이후 기술 시전

Phase1로 구성
왼팔, 오른팔을 주먹으로 사용함

패턴
1. 주먹1: 플레이어 있는 지점으로 주먹으로 내려침
2. 주먹2: 플레이어 있는 방향으로 주먹을 날림

기능 봉인 및 해제
1. 주먹1: 차지 시전 중 봉인 기능을 적중 시 일시적으로 주먹 기능 봉인됨
2. 주먹2: 차지 시전 중 봉인 기능을 적중 시 일시적으로 주먹 기능 봉인됨

봉인 시 제자리로 돌아가고 플레이어와 거리를 벌릴려고 함.

- 플레이어 딜 페이즈
주먹을 사용하는 양팔 봉인 시 코어가 활성화 됨
코어를 처형 메커니즘 시 그로기 상태 돌입 후
딜페이즈 시작 딜페이즈 상태에서 보스의 패턴은 발동하지않음.
딜페이즈 끝날 시 충격파 발산
충격파 발산으로 양팔의 봉인 상태 해제 및 플레이어가 날아가야함.
