# 0. 변경 사항 요약

이 문서는 기존 `Key_README`의 방향성을 현재까지의 기획 대화 기준으로 재정리한 버전이다.

## 주요 변경 사항

### 1. 전투 핵심 구조 변경

기존 구조:

```text
Lock → Unlock → Re-Lock → Break → Expose → Execute
```

변경 구조:

```text
패턴 대응
→ 봉인 기회 확보
→ 부위 봉인
→ 봉인 유지
→ 그로기
→ 코어 활성화
→ 코어 해제
→ 딜 페이즈
→ 충격파
→ 봉인 초기화
→ 반복
```

기존의 `재잠금(Re-Lock)` 개념은 제거한다.

현재 기획의 핵심은 적의 자물쇠를 열고 닫는 것이 아니라,
플레이어가 보스의 부위를 봉인하여 행동 패턴을 제한하고,
그 결과로 그로기와 딜 페이즈를 만들어내는 것이다.

---

### 2. 일반 몬스터 구조 제거

기존에는 일반 적과 보스가 함께 존재하는 액션 로그라이크 구조였으나,
현재 방향에서는 일반 몬스터를 제거하고,
각 층마다 보스가 존재하는 보스 러시 / 보스 레이드 구조로 변경한다.

플레이어는 던전 탑을 올라가며,
각 층의 보스를 공략하고,
패턴을 분석하고,
부위를 봉인하고,
코어를 해제하여 다음 층으로 진행한다.

---

### 3. 열쇠와 자물쇠의 역할 명확화

기존 문서에서는 열쇠, 자물쇠, 잠금, 해제, 재잠금의 의미가 겹쳤다.

현재 구조에서는 아래처럼 정리한다.

| 요소 | 역할 |
|---|---|
| 열쇠 | 플레이어의 무기이자 봉인 집행 도구 |
| 자물쇠 | 적 보스의 부위에 적용되는 봉인 장치 |
| 봉인 | 보스의 특정 부위와 행동 패턴을 제한하는 행위 |
| 해제 | 그로기 상태에서 코어를 열어 딜 페이즈를 시작하는 행위 |
| 잠금 | 별도 용어로 사용하지 않음. 봉인으로 통합 |
| 재잠금 | 제거 |

---

### 4. 딜 페이즈 시스템 추가 및 강화

이제 보스에게 일반 공격을 계속 넣는 방식으로는 체력을 감소시킬 수 없다.

보스의 HP는 딜 페이즈 중 코어를 공격할 때만 감소한다.

따라서 플레이어는 반드시 부위 봉인을 통해 그로기를 만들고,
코어를 해제하여 딜 페이즈를 열어야 한다.

---

### 5. 처형 메커니즘 의미 변경

기존의 처형은 적을 끝내는 강력한 마무리 공격처럼 보일 수 있었다.

현재 기획에서 처형 메커니즘은 적을 죽이는 행위가 아니다.

처형 메커니즘은 플레이어가 보스의 특정 부위에 접근하여,
열쇠를 꽂고,
부위 자물쇠를 봉인한 뒤,
공중제비처럼 빠져나오는 봉인 집행 액션을 의미한다.

즉 처형은 데미지 기술이 아니라,
부위 봉인을 완성하는 연출적 / 조작적 메커니즘이다.

# 5. 핵심 컨셉

플레이어는 열쇠를 사용하는 봉인 집행자다.

강력한 존재들은 신체 곳곳에 봉인 가능한 부위를 가지고 있다.
이 부위들은 단순한 약점이 아니라,
보스의 공격 패턴과 직접 연결된 구조다.

플레이어는 보스의 공격을 피하고,
패턴의 빈틈을 노려 부위를 봉인한다.

부위가 봉인되면 보스는 특정 행동을 사용하지 못하거나,
패턴이 약화되거나,
공격 방식이 변화한다.

일정 수 이상의 부위를 제한 시간 안에 봉인하면,
보스는 그로기 상태에 진입한다.

그로기 상태에서는 숨겨져 있던 코어가 활성화된다.

플레이어는 코어에 접근하여 열쇠로 코어의 봉인을 해제하고,
딜 페이즈를 열어야 한다.

보스의 체력은 딜 페이즈 중 코어를 공격할 때만 감소한다.

# 6. 게임의 핵심 문장

플레이어는 열쇠를 사용해 보스의 부위를 봉인하고,
행동 패턴을 제한하여 그로기를 유도한 뒤,
숨겨진 코어를 해제하여 딜 페이즈를 여는 보스 공략형 액션 게임이다.

# 9. 플레이어

## 플레이어의 역할

플레이어는 보스를 직접 힘으로 압도하는 전사가 아니다.

플레이어는 보스의 구조를 읽고,
위험한 행동을 봉인하며,
보스를 무력화시키는 봉인 집행자다.

플레이어의 공격은 보스를 죽이기 위한 단순 피해 수단이 아니라,
봉인 조건을 만들고,
부위에 접근하고,
코어를 해제하기 위한 도구다.

---

## 플레이어 기본 행동

| 행동 | 설명 |
|---|---|
| 이동 | 좌우 이동 |
| 점프 | 플랫폼 액션 기본 점프 |
| 대시 | 보스 패턴 회피 및 접근 |
| 공중 이동 | 공중 봉인 / 회피를 위한 이동 |
| 기본 공격 | 열쇠 무기를 사용한 근접 공격 |
| 봉인 투사체 | 특정 부위에 봉인 기회를 만드는 원거리 판정 |
| 봉인 집행 | 부위에 접근하여 열쇠를 꽂고 봉인하는 액션 |
| 코어 해제 | 그로기 상태에서 코어를 열어 딜 페이즈 진입 |
| 코어 공격 | 딜 페이즈 중 실제 HP 피해를 주는 공격 |

---

## 플레이어의 주요 목적

플레이어는 보스를 계속 공격하는 것이 아니라,
보스의 패턴을 제한하고 딜 페이즈를 만드는 것을 목표로 한다.

일반 상태에서의 공격은 주로 다음 목적을 가진다.

- 봉인 기회 생성
- 패턴 후딜레이 활용
- 부위 접근
- 봉인 투사체 발사
- 보스의 반격 패턴 유도
- 딜 페이즈 진입 준비

# 10. 적 캐릭터

## 적 구성

현재 기획에서는 일반 몬스터를 제거한다.

모든 주요 전투 대상은 보스이다.

각 보스는 하나의 층 또는 하나의 전투 구역을 대표한다.

---

## 보스 중심 구조

각 보스는 아래 요소를 가진다.

- 고유한 부위 구조
- 고유한 자물쇠 위치
- 고유한 패턴 목록
- 봉인 가능한 패턴
- 봉인 불가능한 패턴
- 봉인 지속 시간
- 그로기 진입 조건
- 코어 활성 조건
- 딜 페이즈 구조
- 딜 페이즈 종료 후 리셋 규칙
- 반격 패턴

---

## 보스의 설계 목적

보스는 단순히 체력이 많은 적이 아니다.

보스는 하나의 퍼즐형 액션 전투 구조다.

그러나 퍼즐처럼 정답을 찾는 게임이 아니라,
실시간 액션 안에서 패턴을 피하고,
빈틈을 파고들며,
봉인 타이밍을 판단하는 전투가 되어야 한다.

# 11. 열쇠

## 열쇠의 정의

열쇠는 플레이어의 무기이다.

열쇠는 단순히 자물쇠를 여는 도구가 아니라,
보스의 부위를 봉인하고,
코어를 해제하며,
전투 리듬을 만들어내는 핵심 장비다.

---

## 열쇠의 역할

열쇠는 다음 역할을 가진다.

- 근접 공격
- 봉인 집행
- 부위 접근
- 봉인 투사체 발사
- 코어 해제
- 공중 액션 보조
- 특정 무기군별 고유 전투 방식 제공

---

## 열쇠 디자인 방향

기존의 다양한 열쇠는 지팡이 또는 스태프처럼 보일 위험이 있었다.

현재 방향에서는 열쇠를 무기군과 결합한다.

열쇠의 앞부분과 뒷부분을 활용하여,
검, 둔기, 창, 대검, 사슬 등의 무기적 실루엣을 가진 열쇠를 만든다.

즉 모든 무기는 열쇠의 정체성을 유지하되,
플레이 방식은 서로 다르게 구성된다.

---

## 근거리 열쇠 무기군

| 무기군 | 설명 |
|---|---|
| 검형 열쇠 | 가장 기본적인 근접 열쇠. 빠른 연속 공격과 안정적인 봉인 집행 |
| 대검형 열쇠 | 느리지만 강한 타격. 큰 부위나 장갑형 보스에게 적합 |
| 둔기형 열쇠 | 자물쇠를 부수듯 찍어 누르는 무기. 그로기 누적에 특화 가능 |
| 창형 열쇠 | 긴 리치와 찌르기 중심. 특정 부위를 정밀하게 노리기 좋음 |
| 쌍열쇠 | 빠른 공중 연계와 다단 공격. 짧은 시간 안에 봉인 조건을 만들기 좋음 |
| 사슬 열쇠 | 중거리 견제와 끌어오기, 공중 접근에 특화 |

---

## 원거리 열쇠 무기군

원거리 무기군은 추후 확장 요소로 둔다.

현재 기획의 우선순위는 근거리 열쇠 무기군이다.

추후 확장 가능 예시는 아래와 같다.

- 석궁형 열쇠
- 소총형 열쇠
- 투척형 열쇠
- 귀환형 열쇠
- 런처형 열쇠

# 12. 자물쇠

## 자물쇠의 정의

자물쇠는 보스의 부위에 적용되는 봉인 장치다.

자물쇠는 적의 HP가 아니다.

자물쇠는 적의 행동 패턴과 연결된 구조적 제어 장치다.

---

## 자물쇠의 역할

자물쇠는 다음 역할을 가진다.

- 보스 부위 봉인 상태 표시
- 패턴 제한
- 행동 약화
- 그로기 조건 구성
- 코어 활성 조건 구성
- 보스의 현재 상태 시각화

---

## 자물쇠의 상태

현재 기획에서는 자물쇠 상태를 단순화한다.

| 상태 | 설명 |
|---|---|
| 비봉인 | 해당 부위가 자유롭게 행동 가능 |
| 봉인 중 | 해당 부위의 일부 행동이 제한되거나 패턴에서 제외됨 |
| 봉인 해제 | 봉인 지속 시간이 끝나거나 딜 페이즈 종료 후 초기화됨 |

`잠금`과 `재잠금`은 별도 상태로 사용하지 않는다.

---

# 13. 봉인

## 봉인의 정의

봉인은 플레이어가 보스의 특정 부위에 자물쇠를 적용하여,
그 부위가 담당하는 행동 패턴을 제한하는 행위다.

봉인은 데미지가 아니다.

봉인은 보스의 행동 구조를 바꾸는 전투 목표다.

---

## 봉인 방식

봉인은 다음 방식 중 하나 또는 조합으로 발생한다.

### 1. 봉인 투사체 적중

플레이어가 봉인 투사체를 발사하여 부위에 맞춘다.

단, 보스는 봉인 투사체를 검으로 쳐내거나,
다른 부위로 대신 맞게 만들 수 있다.

---

### 2. 패턴 후딜레이 접근

보스가 강력한 패턴을 사용한 뒤,
짧은 후딜레이 구간이 발생한다.

플레이어는 이때 부위에 접근하여 봉인 집행을 시도한다.

---

### 3. 봉인 집행

플레이어가 특정 부위 범위 안에서 입력을 유지하면,
캐릭터가 해당 부위로 이동하거나 달라붙어,
열쇠를 꽂고 봉인을 완성한다.

봉인 완료 후 플레이어는 공중제비처럼 빠져나오며,
다시 전투 위치로 복귀한다.

---

## 봉인 지속 시간

봉인은 영구적이지 않다.

각 부위 봉인에는 지속 시간이 존재한다.

플레이어가 제한 시간 내에 추가 봉인을 성공하지 못하면,
먼저 걸린 봉인이 해제된다.

따라서 플레이어는 단일 봉인을 성공하는 것만으로는 충분하지 않다.

여러 부위 봉인을 제한 시간 안에 연속적으로 연결해야 한다.

---

## 봉인의 효과

봉인된 부위는 다음 효과 중 하나 이상을 가진다.

- 해당 부위 패턴 사용 불가
- 해당 부위 패턴 속도 감소
- 해당 부위 패턴 예고 시간 증가
- 특정 반격 패턴 사용 제한
- 그로기 조건에 포함
- 코어 활성 조건에 포함
- 보스 이동 능력 약화
- 보스 방어 능력 약화

---

# 14. 해제

## 해제의 정의

해제는 일반 부위에 사용하는 개념이 아니다.

현재 기획에서 해제는 코어에만 집중한다.

보스가 그로기 상태에 진입하면 숨겨진 코어가 활성화된다.

플레이어는 코어에 접근하여 열쇠로 코어의 봉인을 해제한다.

코어 해제가 완료되면 딜 페이즈가 시작된다.

---

## 해제의 역할

해제는 딜 페이즈를 여는 행위다.

따라서 해제는 봉인과 역할이 다르다.

| 요소 | 대상 | 목적 |
|---|---|---|
| 봉인 | 보스 부위 | 행동 제한 / 그로기 유도 |
| 해제 | 보스 코어 | 딜 페이즈 개방 |

---

# 15. 그로기

## 그로기의 정의

그로기는 보스가 일정 조건을 만족했을 때 무력화되는 상태다.

이 상태에서 보스는 일시적으로 행동을 멈추고,
숨겨진 코어가 노출된다.

---

## 그로기 진입 조건

보스마다 그로기 조건은 다르다.

예시는 아래와 같다.

- 양팔 동시 봉인
- 다리 2개 이상 봉인
- 방패 + 오른팔 동시 봉인
- 날개 양쪽 봉인
- 특정 패턴 중 봉인 성공
- 특정 시간 내 3부위 이상 봉인 유지

---

## 그로기 상태의 특징

- 보스 행동 정지
- 반격 패턴 비활성화
- 코어 활성화
- 코어 해제 가능
- 봉인 집행 가능
- 일정 시간 후 자동 회복

---

## 그로기 실패

그로기 상태에서 제한 시간 내에 코어 해제를 하지 못하면,
보스는 다시 전투 상태로 복귀한다.

복귀 시 충격파가 발생할 수 있으며,
플레이어는 강제로 밀려난다.

---

# 16. 코어

## 코어의 정의

코어는 보스 내부에 숨겨진 핵심 기관이다.

코어는 평상시 보이지 않으며,
보스에게 직접 피해를 줄 수 있는 유일한 핵심 지점이다.

---

## 코어 활성화

코어는 그로기 상태에서만 활성화된다.

코어가 활성화되면 플레이어는 코어에 접근할 수 있다.

---

## 코어 해제

플레이어가 코어에 열쇠를 꽂아 해제하면,
딜 페이즈가 시작된다.

코어 해제는 전투 사이클에서 가장 중요한 전환점이다.

---

# 17. 딜 페이즈

## 딜 페이즈의 정의

딜 페이즈는 보스의 HP를 감소시킬 수 있는 유일한 구간이다.

평상시 보스의 부위를 공격해도 HP는 감소하지 않는다.

---

## 딜 페이즈 진입 조건

```text
일정 부위 이상 봉인
→ 그로기
→ 코어 활성화
→ 코어 해제
→ 딜 페이즈 진입
```

---

## 딜 페이즈 중 상태

- 보스 행동 정지
- 코어 피격 가능
- HP 감소 가능
- 반격 패턴 비활성화
- 봉인 투사체 방어 패턴 비활성화
- 제한 시간 존재

---

## 딜 페이즈 종료

딜 페이즈가 종료되면 아래 흐름이 발생한다.

```text
코어 비활성화
→ 충격파 발생
→ 플레이어 밀림
→ 부위 봉인 초기화
→ 보스 패턴 재개
```

---

# 18. 충격파

## 충격파의 정의

충격파는 딜 페이즈 종료 또는 페이즈 전환 시 발생하는 밀침 효과다.

충격파는 데미지를 주는 공격이 아니다.

충격파의 목적은 플레이어를 보스에게서 떨어뜨리고,
다음 전투 사이클을 시작하게 만드는 것이다.

---

## 충격파 발생 조건

- 딜 페이즈 종료
- 그로기 회복
- 페이즈 전환
- 특정 보스 패턴 종료
- 코어 해제 실패 후 복귀

---

# 19. 보스 반격 시스템

## 개요

보스는 플레이어의 봉인 시도를 무조건 허용하지 않는다.

플레이어가 봉인 투사체를 발사하거나,
부위 봉인을 시도할 때,
보스는 특정 반격 시스템으로 이를 막을 수 있다.

---

## 검 무식

검을 사용하는 보스가 플레이어의 봉인 투사체를 쳐내는 반응형 패턴이다.

무작정 봉인 투사체를 발사하면 실패한다.

플레이어는 보스의 반격 쿨타임,
패턴 후딜레이,
공격 방향을 고려하여 봉인을 시도해야 한다.

---

## 대타 출동

보스의 특정 부위가 봉인 투사체를 대신 맞는 시스템이다.

예를 들어 플레이어가 코어나 팔을 노렸지만,
보스의 다른 팔이 대신 봉인 투사체를 막을 수 있다.

이 경우 의도한 부위가 아닌 다른 부위가 봉인되거나,
봉인 흐름이 변경된다.

---

## 반격 시스템의 목적

반격 시스템은 봉인을 단순한 명중 판정으로 만들지 않기 위한 장치다.

플레이어는 다음을 판단해야 한다.

- 지금 봉인 투사체를 쏴도 되는가
- 보스가 검 무식을 사용할 수 있는가
- 대타 출동 가능한 부위가 남아 있는가
- 패턴 후딜레이를 기다리는 것이 좋은가
- 가까이 접근해서 봉인 집행을 하는 것이 좋은가

---

# 20. 보스 페이즈 구조

## 기본 구조

각 보스는 여러 페이즈를 가질 수 있다.

페이즈가 진행될수록 다음 요소가 변화한다.

- 패턴 수 증가
- 패턴 속도 증가
- 봉인 가능 구간 감소
- 반격 패턴 강화
- 봉인 지속 시간 감소
- 코어 해제 난이도 증가
- 딜 페이즈 지속 시간 변화

---

## 페이즈 전환

페이즈 전환 시 보스는 잠시 무적 상태가 된다.

전환 연출이 재생되고,
충격파가 발생하며,
부위 봉인 상태가 초기화된다.

---

# 21. 보스 설계 원칙

모든 보스는 아래 구조를 가져야 한다.

## 1. 부위 구조

보스는 봉인 가능한 부위를 가진다.

예:

- 오른팔
- 왼팔
- 다리
- 날개
- 방패
- 검
- 꼬리
- 머리
- 추가 팔

---

## 2. 패턴 연결

각 부위는 특정 패턴과 연결된다.

예:

| 부위 | 연결 패턴 |
|---|---|
| 오른팔 | 검 공격 |
| 왼팔 | 방패 방어 |
| 다리 | 돌진 |
| 날개 | 비행 |
| 머리 | 추적 / 레이저 |
| 추가 팔 | 잡기 / 대타 출동 |

---

## 3. 봉인 효과

부위가 봉인되면 연결된 패턴이 제한된다.

단순히 공격력이 감소하는 것이 아니라,
전투 구조가 달라져야 한다.

---

## 4. 그로기 조건

보스마다 그로기 조건이 다르다.

조건은 단순 수치보다 구조 기반이어야 한다.

예:

- 양팔 동시 봉인
- 날개 2개 봉인
- 다리 4개 중 3개 봉인
- 방패 봉인 후 검 봉인
- 특정 패턴 도중 봉인 성공

---

## 5. 딜 페이즈 조건

딜 페이즈는 반드시 코어 해제를 통해서만 열린다.

그로기는 딜 페이즈가 아니라,
딜 페이즈를 열기 위한 준비 상태다.

---

# 22. 보스 예시 — 봉인된 기사

## 개요

봉인된 기사는 플레이어에게 핵심 전투 루프를 학습시키는 첫 번째 보스다.

기존 문서에서는 봉인된 상태에서 시작하여,
플레이어가 재잠금을 반복하는 구조였으나,
현재 기획에서는 재잠금 개념을 제거하고,
부위 봉인을 통해 그로기를 만드는 구조로 변경한다.

---

## 주요 부위

| 부위 | 역할 |
|---|---|
| 방패 | 전방 방어 / 돌진 패턴 |
| 왼팔 | 방패 패턴과 방어 행동 |
| 오른팔 | 검 또는 주먹 공격 |
| 코어 | 그로기 상태에서만 노출되는 딜 페이즈 진입 대상 |

---

## 기본 루프

```text
기사 패턴 회피
→ 방패 / 팔의 후딜레이 확인
→ 부위 봉인
→ 제한 시간 내 추가 봉인
→ 양팔 또는 특정 부위 조건 충족
→ 그로기
→ 코어 활성화
→ 코어 해제
→ 딜 페이즈
→ 충격파
→ 봉인 초기화
→ 반복
```

---

## 기사 보스의 특징

- 전방 방어 능력이 강함
- 무작정 공격하면 피해를 줄 수 없음
- 봉인 투사체를 검으로 쳐낼 수 있음
- 특정 상황에서 다른 부위가 대신 봉인 투사체를 맞을 수 있음
- 딜 페이즈 종료 시 충격파로 플레이어를 밀어냄
- 봉인 지속 시간이 있어 연속적인 봉인 판단이 필요함

---

# 23. 성장 요소

## 성장 방향

성장은 단순 공격력 증가보다,
봉인 루프를 더 다양하게 만드는 방향으로 설계한다.

---

## 열쇠 강화

- 공격 속도 증가
- 봉인 집행 속도 증가
- 공중 봉인 가능
- 봉인 투사체 속도 증가
- 봉인 투사체 관통
- 봉인 지속 시간 증가
- 코어 해제 시간 감소

---

## 봉인 강화

- 봉인 지속 시간 증가
- 첫 봉인 성공 시 이동 속도 증가
- 연속 봉인 성공 시 추가 효과
- 특정 부위 봉인 시 충격파 회피 가능
- 봉인 성공 후 공중 대시 회복
- 봉인 실패 시 쿨타임 감소

---

## 딜 페이즈 강화

- 딜 페이즈 지속 시간 증가
- 코어 공격 피해 증가
- 코어 해제 성공 시 추가 시간 획득
- 딜 페이즈 종료 전 탈출 가능
- 코어 공격 중 슈퍼아머 획득

---

# 24. 비주얼 컨셉

## 핵심 비주얼

- 거대한 자물쇠
- 신체 부위에 박힌 봉인 장치
- 열쇠 형태의 무기
- 코어 노출 연출
- 금속과 봉인의 결합
- 기계식 변형
- 부위 봉인 시 시각적 잠김 효과
- 딜 페이즈 중 코어 발광
- 충격파로 전투 리듬을 끊는 연출

---

## 열쇠 무기 비주얼

열쇠는 단순한 스태프가 아니어야 한다.

무기 형태를 유지하되,
실루엣과 장식에서 열쇠의 정체성이 드러나야 한다.

예:

- 검 손잡이 끝이 열쇠 고리 형태
- 칼날 끝이 열쇠 이빨 형태
- 둔기의 타격부가 자물쇠를 누르는 형태
- 창날이 길게 뻗은 열쇠 이빨 형태
- 사슬 끝에 열쇠 머리가 달린 형태

# 28. 정리

현재 기획의 핵심은 더 이상 `잠금 → 해제 → 재잠금`이 아니다.

현재 핵심은 아래 구조다.

```text
보스 패턴을 피한다.
빈틈을 찾는다.
부위를 봉인한다.
제한 시간 안에 봉인을 연결한다.
보스를 그로기 상태로 만든다.
코어를 해제한다.
딜 페이즈에서 피해를 준다.
딜 페이즈가 끝나면 다시 공략한다.
```

이 구조를 통해 플레이어는 무작정 공격하는 것이 아니라,
보스의 행동 패턴을 제한하고,
전투 흐름을 스스로 만들어가는 경험을 하게 된다.
