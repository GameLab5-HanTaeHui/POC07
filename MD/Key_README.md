## 핵심 컨셉

세상의 모든 존재는 "잠겨" 있다.

적들은 신체 곳곳에 거대한 자물쇠를 달고 있으며,
플레이어는 특수 무기인 **열쇠**를 사용하여
적의 봉인을 해제하고 내부 코어를 파괴해야 한다.

단순히 공격만 해서는 적을 죽일 수 없다.
적의 자물쇠를 찾아, 방향을 공략하고, 틈을 만들고, 봉인을 해제해야만 한다.

## 핵심 게임플레이

플레이어는 다양한 형태의 열쇠 무기를 사용한다.
열쇠는 단순 무기가 아니라 공격 / 해제 / 이동 / 상호작용 / 기믹 조작을 동시에 수행하는 전투 도구다.

적들은 각기 다른 위치와 구조의 자물쇠를 가지고 있으며,
플레이어는 이동 액션과 전투 기술을 활용해 자물쇠를 해제해야 한다.

자물쇠가 해제되면:
- 보호막 붕괴
- 약점 노출
- 행동 패턴 변화
- 내부 코어 노출
- 부위 파괴

등이 발생한다.

## 전투 구조

### 1. 탐색
적의 자물쇠 위치와 구조를 파악한다.

### 2. 해제
열쇠 무기를 사용해 특정 방향의 자물쇠를 공격한다.

일부 자물쇠는:
- 특정 각도
- 공중 공격
- 후면 공격
- 순서 해제
- 동시 타격

등 특수 조건이 존재한다.

### 3. 개방
자물쇠가 열리면 적의 내부가 노출된다.
코어 / 동력부 / 기생체 / 에너지 기관 등이 드러난다.

### 4. 처형
노출된 약점을 집중 공격하여 적을 파괴한다.

## 열쇠 무기 목록

| 무기 | 유형 | 설명 |
|---|---|---|
| 녹슨 열쇠 | 근접 | 기본 근접형. 빠른 연속 해제. 3단 콤보 + 공중 공격. |
| 갈고리 열쇠 | 훅 | 적 자물쇠에 걸어 끌어당기거나 플레이어가 이동. |
| 태엽 열쇠 | 회전 | 회전하며 다수 자물쇠를 동시 해제. |
| 분열 열쇠 | 투사체 | 충돌 시 여러 개로 분열. |
| 공명 열쇠 | 광역 | 해제된 자물쇠 근처에서 추가 반응 발생. |
| 중력 열쇠 | 변형 | 자물쇠 방향을 뒤집는다. |
